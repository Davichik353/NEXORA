# NEXORA Commerce

Интерактивная демонстрация интернет-магазина электроники и CRM на **Next.js 15, React 19 и TypeScript**.

## Запуск

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`. По умолчанию открывается CRM. Магазин доступен по `/?mode=shop&view=catalog`, CRM — по `/admin/`.

```bash
npm run build
```

Сборка экспортирует сайт в `out/`; его можно разместить на статическом хостинге. Node.js 20.9+.

## Возможности

- CRM: обзор, график выручки и заказов, распределение продаж по категориям, популярные товары, экспорт CSV.
- Товары: добавление, редактирование, SKU, цена, себестоимость, количество.
- Заказы: поиск, фильтрация, пагинация, карточка заказа, изменение статуса. Отмена возвращает товары на склад; восстановление проверяет наличие.
- Клиенты: база на основе покупок, сегменты, история заказов.
- Склад: остатки, предупреждения о низком запасе, оценка запасов по себестоимости.
- Промокоды: создание, активация и отключение, применение при оформлении заказа.
- Команда: демонстрационный список сотрудников и ролей.
- Магазин: каталог, поиск, фильтры цены/бренда/категории, сортировка, карточки товаров, избранное, корзина, демопрофиль и история покупок.
- Сквозная покупка: оформление → симуляция оплаты → новый заказ в CRM → уменьшение остатков.
- Адаптивный интерфейс на русском языке.

## Границы демоверсии

Данные сохраняются **только в localStorage текущего браузера**. Все начальные клиенты и заказы вымышлены. Роли сотрудников носят демонстрационный характер и не ограничивают доступ. Демопрофиль покупателя не является авторизацией. Оплата симулируется без платёжного провайдера; письма и посылки не отправляются. Не вводите реальные персональные или банковские данные.

PostgreSQL, Prisma, Redis, серверная авторизация и реальный платёжный sandbox пока **не реализованы**. Это фронтенд-прототип, а не готовая к реальным продажам бизнес-система. Стили написаны на CSS; Tailwind и Docker в текущей версии не используются.

## Проверка основного сценария

1. Откройте магазин через кнопку в боковой панели.
2. Добавьте iPhone в корзину, затем нажмите «Оформить заказ».
3. Заполните тестовые данные, примените `NEXORA10`.
4. Нажмите «Оформить тестовый заказ», перейдите в CRM.
5. Откройте новый заказ и измените статус на «Отменён» — остаток восстановится.
6. Перезагрузите страницу: изменения сохранятся. Для сброса демо очистите localStorage сайта.

## Структура

- `app/commerce.tsx` — интерфейс и логика демосценариев.
- `app/globals.css` — дизайн и адаптивная сетка.
- `app/page.tsx`, `app/admin/page.tsx` — точки входа.
- `public/assets/` — фотографии товаров (Unsplash).
- `scripts/dev.mjs` — запуск Next.js с поддержкой аргумента `--port`.
